# Универсальный бот-информатор для инвестирования

## Предпосылки
При активном использовании стратегии [скальпинга](https://skillbox.ru/media/money/skalping-chto-o-nem-nuzhno-znat-i-kakoy-dohod-on-mozhet-prinesti/) я столкнулся с проблемой: постоянный мониторинг биржи отнимает много времени и внимания. Стандартное брокерское приложение уведомляет о достижении ценой заданного уровня, но мне не хватало двух ключевых функций:
1.  **Аналитики в разрезе отдельных сделок**, а не усреднённых показателей по активу.
2.  **Прогноза потенциального дохода** до совершения сделки, чтобы оценить её целесообразность.

Так появилась идея этого бота-информатора.

## Архитектура проекта
Проект построен на принципах **гексагональной архитектуры (Ports & Adapters)**. Бизнес-логика отделена от внешних источников данных, что позволяет легко адаптировать систему под любой API брокера или инвестиционной платформы.

```
trade-informer/
├── bot/ # Telegram-бот (aiogram)
│ ├── main.py # Точка входа, сборка зависимостей
│ ├── handlers/ # Обработчики команд (/add, /report и др.)
│ ├── schedulers/ # Фоновые задачи (рассылка отчётов)
│ └── middlewares/ # Промежуточные слои (Rate Limiting и др.)
├── core/ # Бизнес-логика (не зависит от внешнего мира)
│ ├── ports.py # Абстрактные интерфейсы (контракты)
│ ├── adapters/ # Реализации интерфейсов (MOEX, Telegram)
│ └── services/ # Сервисы-калькуляторы
├── infrastructure/ # Инфраструктура (БД, репозитории)
│ ├── database/ # SQLAlchemy модели и подключение к PostgreSQL
│ └── repositories/ # Реализации репозиториев
├── migrations/ # Миграции Alembic для управления схемой БД
├── tests/ # Юнит-тесты
├── logs/ # Логи приложения с автоматической ротацией
├── .env.example # Пример файла с переменными окружения
├── Dockerfile # Контейнеризация
├── docker-compose.yaml # Запуск бота и БД одной командой
├── requirements.txt # Зависимости
└── README.md # Этот файл
```
**Ключевые компоненты:**
*   `core/ports.py` — Определяет контракт, который должны выполнять все провайдеры данных и репозитории.
*   `adapters/MoexPriceProvider.py` — Актуальная реализация с использованием бесплатного API MOEX.
*   `services/PositionMonitor.py` — Сервис-калькулятор, который, используя переданный провайдер, рассчитывает P&L и проверяет условия для срабатывания сигналов.
*   `bot/middlewares/` — Реализация Rate Limiting'а для предотвращения флуда.
*   `tests/` — Модульные тесты для проверки бизнес-логики.
*   `schedulers/` — Рассылатели, используются сейчас для рассылки пользователям аналитику портфеля каждые N секунд.

## Требования к окружению
*   Python 3.13 или выше
*   Docker и Docker Compose (для быстрого запуска)


## Быстрый запуск (Quick Start)

### Через Docker (рекомендуемый способ)
1.  Клонируйте репозиторий: `git clone <URL>`
2.  Скопируйте `.env.example` → `.env.docker` и заполните его реальными данными (токен бота, параметры БД, конфигурация для rate limiting, интервал отправки отчёта).
3.  Выполните команду: `docker-compose up --build`
4.  Готово! Бот будет доступен в Telegram сразу после запуска.

### Ручной запуск (для разработки)
1.  Клонируйте репозиторий: `git clone https://github.com/samthezpub/trade-informer`
2.  Создайте виртуальное окружение: `python -m venv venv` и активируйте его.
3.  Установите зависимости: `pip install -r requirements.txt`
4.  Примените миграции: `alembic upgrade head`
5.  Запустите бота: `python bot/main.py`

## Стек технологий
- **Язык:** Python 3.13
- **Бот:** aiogram 3.x
- **База данных:** PostgreSQL + SQLAlchemy (асинхронный режим) + Alembic (синхронный)
- **Логирование:** Loguru (структурированное, с ротацией)
- **Тестирование:** Pytest
- **Контейнеризация:** Docker + Docker Compose
- **API биржи:** MOEX (открытый и бесплатный)
- **Архитектура:** Гексагональная (Ports & Adapters)
